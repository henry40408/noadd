{# The statistics page. The split here is the one the data draws for itself. `tz_offset` reaches exactly two computations — `compute_stats_timeline` and `compute_heatmap` — and those two feed exactly the three charts below. A calendar-aligned bucket needs the viewer's UTC offset, which arrives with the browser rather than with the request, and the charts were already the documented exception to this UI working without JavaScript. So the charts say they are drawn in the browser, and `app.js` fetches them with the offset. Everything else is a plain `now - range` window with no calendar in it: the highlights, both breakdowns, both ranged lists and the health grid are rendered here and never move again. `app.js` does not redraw them, which is why there is no second copy of this markup in it. The range switcher is three links rather than three buttons for the same reason every other view on this UI is in the URL: the range picks the server's window, so `?range=30d` can be refreshed, bookmarked and shared. #} {% extends "shell.html" %} {%- import "_macros.html" as macros -%} {% block page %}
